# VPS Backup

A personal automation tool for backing up Virtual Private Server (VPS) data to Google Drive with Telegram notifications.

## About

This application is a personal-use tool that:
- Automatically creates backups of VPS server data.
- Uploads backup archives to a private Google Drive folder.
- Sends status notifications via Telegram.
- Manages backup rotation (7 days local, 30 days on Google Drive).
